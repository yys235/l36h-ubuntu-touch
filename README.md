# Xperia Z L36H / yuga — Ubuntu Touch 20.04 与服务器部署

**发布准备中。这里暂不提供可直接执行的完整刷机流程。**

本项目整理 Sony Xperia Z L36h（yuga / APQ8064）运行 Ubuntu Touch
20.04.6 ARMHF 的适配成果，以及 TF 卡上的 Hermes 服务部署。
目标是让安装者使用固定版本的匹配镜像和源码复现，而不是依赖原作者的机器环境。

## 当前发布范围

| 项目 | 状态 / 边界 |
|---|---|
| Ubuntu Touch | 20.04.6 ARMHF 已进入桌面；24.04 不在当前可刷支持范围 |
| 内核 | Halium yuga Linux 3.4.113，加兼容性与缺陷修复；完整修改集待导出 |
| 显示/电源键 | 已确认实际背光为 LM3533；接口修复实机关屏、唤醒通过 |
| 服务器模式 | 关屏保留 CPU/网络运行；防休眠服务已部署，长期及重启验收待汇总 |
| 外接 TF 卡 | ext4；Hermes 和 swap 可运行；不得复制作者的卡 UUID |
| Hermes | 官方固定源码，ARMv7 私有运行环境；可选工具不全等同官方自动安装支持 |
| HTTPS | 手机 Caddy 代理与 Hermes 共用外部9119端口；每台安装设备应生成自己的 CA |
| 稳定性 | 历史存在内核 panic；已修复有明确证据的一类 skb 释放后使用问题，其他归因尚未全部完成 |
| 相机 | 用户选择屏蔽，不宣称可用 |

## 将提供的材料

1. 中文刷机指南、恢复步骤、分区识别与刷写前校验。
2. 对应镜像、SHA256、完整源码引用和归档，以及许可证说明。
3. 固定工具链、源码提交、补丁顺序和构建配置。
4. SSH、TF 卡、swap、背光和服务器模式安装配置。
5. Hermes ARMv7 部署、HTTPS、本地证书信任和迁移备份指南。
6. 已测功能表、已知故障和未验证项目。

当前中文指南草稿见 [GUIDE.zh-CN.md](GUIDE.zh-CN.md)，它明确区分已经
核实的布局和仍缺少的发行步骤。传输脚本9项接收测试与4项发送测试
通过，属于主机协议验证，不能据此宣称新设备刷机已复现。

实机验证与已知限制见 [STATUS.md](STATUS.md)。已确认一类skb缺陷并
回移修复，但其他历史内核崩溃尚未全部归因，长期稳定性不作已通过承诺。

公开发行不包含作者账号密码、私钥、模型凭据、会话数据库或设备校准数据。
不同设备的 bootloader、TA/校准等分区不可互相克隆。
